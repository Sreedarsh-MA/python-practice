# Python Learning Hub
A unified CLI application consolidating fundamental Python lessons.

## Features
- **User Profile**: Collects user data and calculates age.
- **Grade Checker**: Simple pass/fail logic for exam results.
- **ATM Simulator**: PIN-protected balance withdrawal simulation.

## Installation
1. Ensure you have Python 3.x installed.
2. Download or clone this project folder.

## How to Run
Run the main entry point from your terminal:
```bash
python main.py
```
